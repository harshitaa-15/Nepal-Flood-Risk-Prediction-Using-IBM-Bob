# Nepal-Flood-Risk-Prediction-Using-IBM-Bob
Developed an AI-powered flood risk prediction system using Python and Machine Learning to classify flood risk as LOW, MEDIUM, or HIGH. Performed EDA, feature engineering, SMOTE balancing, and evaluated multiple models, with Random Forest achieving 87.65% weighted F1 and 0.9788 ROC-AUC. Built an interactive Streamlit dashboard.
